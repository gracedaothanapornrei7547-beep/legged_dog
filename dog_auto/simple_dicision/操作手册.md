# simple_dicision 操作手册

> 全流程：建图 → 打点 → 启动导航通信 → 启动决策机 → 输入颜色 → 跑完放置。
> 每开一个新终端，第一件事：`source ~/dog_auto/setup-env.sh`

---

## 1. 建图（新场地只做一次）

```bash
# 终端1: 狗底盘（常驻）
source ~/dog_auto/setup-env.sh
ros2 launch nav_bringup dog_bringup.launch.py

# 终端2: 建图（Ctrl+C 自动存）
~/dog_auto/desnap-ros.sh ros2 run nav_bringup run_mapping --map-name test --rviz

# 终端3: 遥控开狗
ros2 run legged_nav_ros sbus_teleop
```

遥控 ch5 低位，推摇杆走遍全场，Rviz 看地图扫全 → 终端2 Ctrl+C 存图。

---

## 2. 打点（新场地只做一次）

```bash
# 终端1: 狗底盘
source ~/dog_auto/setup-env.sh
ros2 launch nav_bringup dog_bringup.launch.py

# 终端2: 定位（等 Rviz 里狗位置稳定不再跳）
source ~/dog_auto/setup-env.sh
ros2 launch nav_bringup dog_navigation.launch.py map_name:=test run_nav2:=False use_rviz:=true

# 终端3: 遥控开狗
ros2 run legged_nav_ros sbus_teleop

# 终端4: 打点（狗停稳、ch5 高位后逐一敲）
ros2 run simple_nav_fsm record_waypoint t1     # 起点
ros2 run simple_nav_fsm record_waypoint t2     # 抓取点
ros2 run simple_nav_fsm record_waypoint t3     # 过减速带点
ros2 run simple_nav_fsm record_waypoint tt1    # 放置区 0
ros2 run simple_nav_fsm record_waypoint tt2    # 放置区 1
ros2 run simple_nav_fsm record_waypoint tt3    # 放置区 2
ros2 run simple_nav_fsm record_waypoint tt4    # 放置区 3
```

打完 `cat ~/.simple_nav_fsm_waypoints.yaml` 确认 7 个点都在。

## 3. 实测全流程（每次比赛跑这套）

### 终端1 — 狗底盘

```bash
source ~/dog_auto/setup-env.sh
ros2 launch nav_bringup dog_bringup.launch.py
```

一直开着别关。

### 终端2 — 定位

```bash
source ~/dog_auto/setup-env.sh
ros2 launch nav_bringup dog_navigation.launch.py map_name:=arena run_nav2:=False use_rviz:=true
```

等 Rviz 里狗位稳定。

### 终端3 — 导航 FSM

```bash
source ~/dog_auto/setup-env.sh
ros2 launch simple_nav_fsm simple_nav.launch.py
```

> ⚠ 遥控器 ch5 高位或拔掉接收。

### 终端4 — 决策机

```bash
source ~/dog_auto/setup-env.sh
ros2 launch simple_dicision simple_mission.launch.py \
  left_color:=red right_color:=blue auto_start:=False
```

| 参数 | 颜色 | 对应路点(test) |
|------|------|------|
| `left_color` | `green` / `gray` / `blue` / `red` | 左托盘 → 对应 place_* |
| `right_color` | `green` / `gray` / `blue` / `red` | 右托盘 → 对应 place_* |

也支持数字编号：`0`=绿 `1`=灰 `2`=蓝 `3`=红，中文：`绿` `灰` `蓝` `红`。

**`left_color` → 左托盘 (AB 05 01)，`right_color` → 右托盘 (AB 05 02)**。

启动后手动扳机：

```bash
ros2 service call /simple_dicision/start std_srvs/srv/Trigger
```

狗自动执行：

```
S0  初始化 X5        AB 01 00 BA → 等 s3=02
S3  进场             t1 → t2
S4  抓取             AB 04 01 BA → 等 s3=02   (X5 抓左右箱)
S5  过减速带          t3
S6  放左             走到 tt* → AB 05 01 BA → 等 s3=02
S6  放右             走到 tt* → AB 05 02 BA → 等 s3=02
DONE  完赛
```

## 4. 急停

```bash
ros2 service call /simple_dicision/abort std_srvs/srv/Trigger
```

取消导航 + 停机械臂。

## 6. dry_run 彩排（本机模拟，不开串口不导航）

```bash
source ~/dog_auto/setup-env.sh
echo -e "red\nblue" | ros2 run simple_dicision simple_mission_node \
  --ros-args -p dry_run:=True \
  -p route_config:=/home/angel/dog_auto/simple_dicision/config/mission.yaml
```

## 7. 换场地 / 重新打点后

编辑 `config/mission.yaml`，把右边的点名换成新的：

```yaml
route:
  start:    "t1"
  grab:     "t2"
  cross:    "t3"
  place_green:  "tt1"
  place_gray:   "tt2"
  place_blue:   "tt3"
  place_red:    "tt4"
```

重新编译：

```bash
cd ~/dog_auto && colcon build --packages-select simple_dicision --symlink-install
```

---

## 8. 串口设备不对

```bash
# 确认设备
ls /dev/ttyX5 /dev/ttyUSB0

# 启动时指定
ros2 launch simple_dicision simple_mission.launch.py serial_port:=/dev/ttyUSB0
```

## 9. 故障速查

| 现象 | 处置 |
|------|------|
| 决策机报"导航服务器未就绪" | 终端3 FSM 没起，等几秒或重起 |
| 报"路点不存在" | `cat ~/.simple_nav_fsm_waypoints.yaml` 核对点名 |
| X5 无反应 | `ls /dev/ttyX5`；用 debug_console.py 手动测 |
| 狗一 launch 就窜 | 加 `auto_start:=False` |
| 放反了托盘 | 第一个输入=左托盘，第二个=右托盘 |
