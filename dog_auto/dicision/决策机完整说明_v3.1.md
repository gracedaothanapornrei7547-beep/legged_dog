## 0. 相对之前版本的两处协议变更（X5 已实现，主机须对齐）

### 变更① 移动帧：距离值 → 方向标志

| | 之前 v3 文档写的 | **X5 实际实现（对齐这个）** |
|---|---|---|
| 帧格式 | `EF x y z FE` 14字节3float | **不变**，14字节3float |
| 值语义 | x/y/z = "还差多少米" | **方向标志 0.0不动 / 1.0正 / 2.0负** |
| 字段1 | x（右+米） | **x轴：1=右, 2=左** |
| 字段2 | y（前+米） | **y轴：1=前, 2=后** |
| 字段3 | z（上下，忽略） | **yaw：1=顺时针, 2=逆时针** |
| 三轴关系 | — | **各自独立、可同时非0** |

**执行方式（已和用户确认）**：每收到一帧方向标志，主机按**固定小速度**朝各非0轴的指定方向挪**一个固定小步长**（如挪 0.2 秒）后停；X5 不够会再发下一帧。**不是**持续动到全0才停，而是**一帧一小步**。

> 微调因此回到"方向标志 + 固定小步"模式（比距离值更简单，主机不用算换算函数，X5 全权控制逼近节奏）。

### 变更② 数字帧 8箱字节 + 答案字节：颜色码 → 归位区编号

| | 之前 v3 文档写的 | **X5 实际实现（对齐这个）** |
|---|---|---|
| 8箱编码 | 颜色码 1红/2蓝/3灰/4绿 | **归位区编号 0食品(绿)/1工具(灰)/2仪器(蓝)/3药品(红)** |
| 未检测 | 未定义 | **0xFF** |
| 答案字节 | 算式结果，另做映射 | **结果 % 4 = 高分区编号 0~3**，和箱字节同一套编号 |

**全链路统一编号（颜色码 1-4 彻底作废）**：

```
编号   区/箱      颜色    place 路点        RGB(图册)
 0    食品箱区    绿      place_green      117,189,66
 1    工具箱区    灰      place_gray       128,128,128
 2    仪器箱区    蓝      place_blue        46, 84,161
 3    药品箱区    红      place_red        200, 29, 49
0xFF  未检测      —       —                —
```

好处：**答案字节和箱字节同一套编号，主机直接"箱编号 == 区编号"比对**，无需任何颜色↔编号转换。高分区编号 = 答案字节。

- **机械臂 X5**：识别、认箱、抓、放；够不着时发方向标志请求挪狗。

## 2. 全流程总览（五阶段）

```
S0 初始化 → S1 识别+扫描 → S2 规划(一次算完整趟) → S3~S6 单趟搬运 → 完赛
```

```
S0 初始化   开串口 → 等导航服务上线 → 点清 15 个路点
            → 发 AB 01 00(初始化) → 等 s3=02
            (任一项没过就停在这)

S1 识别+扫描 狗在启动区原地不动:
            发 AB 02 00(数字识别) → 收数字帧【答案=高分区编号】
            发 AB 03 00(扫描8箱)  → 收数字帧【8箱区编号, 0xFF=未检测】

S2 规划     全场唯一动脑, 一次定死三件事:
            ① 选哪条缝 (§4): 只看 back 排 idx0-3, 三缝各对应相邻两箱
                异色(同色缝弃) → 含高分优先 → 平票选路径最短
            ② 两放置区先后 (§5, 写死偏好方向, 不算真实距离):
                左缝→靠左优先 · 右缝→靠右优先 · 中缝→中间优先 · 平票先左后右
            ③ 整趟路径一次排定:
                home→entry→gapXX_pre→gapXX_back→zoneXX_approach→区A→区B

S3 进场     按序发点, 导航送狗进缝停稳

S4 抓箱     【导航停】发 AB 04 02(抓右)→(停-发-调-干)→等完成
                     发 AB 04 01(抓左)→(停-发-调-干)→等完成
            记住"左托盘=X编号 / 右托盘=Y编号"

S5 过带     发点 gapXX_back→zoneXX_approach, 直穿减速带停稳

S6 放箱     按②顺序到区A:【导航停】比对区编号↔托盘编号:
                区编号==左托盘编号 → 发 AB 05 01(放左托盘)
                区编号==右托盘编号 → 发 AB 05 02(放右托盘)
                →(停-发-调-干)→等完成
            再去区B → 同样比对 → 放另一侧 → ✅ 完赛
```

## 3. "停-发-调-干"闭环（S4抓、S6放每次动手都走它）

```
导航把狗停在固定点 → B 发命令 → 机械臂试着干
   ├─ 对得准 → s3=02 完成
   └─ 差一点 → s3=04(需微调) + 移动帧(方向标志)
         → B 按各非0轴的方向, 固定小速度挪一个固定小步长(如0.2s)后停
         → 机械臂接着看接着干(不够会再发一帧, 可反复)
         → s3=02 完成
铁律: 狗动时机械臂闭眼(一动摄像头就不准), 机械臂看时狗不动 —— 永不同时动。
```

移动帧方向标志 → 底盘速度映射（固定小速度，各轴独立）：
```
字段1 x轴: 1→右移(+vy或按底盘定义) / 2→左移
字段2 y轴: 1→前进(+vx)          / 2→后退
字段3 yaw: 1→顺时针转           / 2→逆时针转
每帧只挪固定小步长(时长×固定小速度), 走 /cmd_vel_raw 经 guard 限速。
```

## 4. 选缝策略（S2 判断①）

```
只搬 back 排(靠减速带, idx0-3), front 排(idx4-7)完全不搬。
三条缝各对应 back 排相邻两箱:
   gap01 → idx0 + idx1
   gap12 → idx1 + idx2
   gap23 → idx2 + idx3

高分区编号 = 答案字节(0~3)。含高分箱 = 该缝两箱里有编号==答案的。

选缝三步:
  规则1 异色硬性: 两箱编号相同的缝 → 舍弃(一趟每区只放一箱)
  规则2 高分优选: 异色缝里含高分箱的优先
  规则3 平票兜底: 分数相同 → 选路径最短的

  未检测(0xFF)处理: 含 0xFF 的箱视为不可用, 该缝按"无法保证异色"弃
                    (或按实测策略, 详见实现时与用户确认)
```

```
归位区左→右: 绿0 · 灰1 · 蓝2 · 红3

  左缝 gap01 → 靠左优先(区编号小的先去)
  右缝 gap23 → 靠右优先(区编号大的先去)

  gap12+{绿0,蓝2} → 蓝中绿边→ 先蓝2 再绿0
```

## 6. 放置左右判断（S6，区编号比对托盘编号）

```
抓取时 B 已记下: 左托盘编号、右托盘编号(两者必不同)。
到某归位区(车头正对):
  当前区编号 == 左托盘编号 → 发 AB 05 01 BA (放左托盘的箱)
  当前区编号 == 右托盘编号 → 发 AB 05 02 BA (放右托盘的箱)
  (两托盘编号不同, 必有且仅有一侧匹配当前区)
左/右托盘的箱都往正前方放进这一个区; 05 01/02 只决定机械臂取哪侧托盘。
```

## 7. 协议帧速查（v3.1 最终）

### B→A 命令帧 4字节 `AB s1 s2 BA`
| s1 | s2 | 含义 |
|----|----|------|
| 01 | 00 | 初始化 |
| 02 | 00 | 数字识别 |
| 03 | 00 | 扫描8箱 |
| 04 | 01 | 抓左托盘 |
| 04 | 02 | 抓右托盘 |
| 05 | 01 | **放左托盘**（v3 重定义，原"第1层"作废）|
| 05 | 02 | **放右托盘**（v3 重定义，原"第2层"作废）|

### A→B 状态帧 5字节 `AB s1 s2 s3 BA`
s3: 01运行 / 02完成 / 03中断 / 04需微调(随后跟移动帧)。**不变。**

### A→B 数字帧 11字节 `CD 答案 箱0..7 DC`
- 答案 = 高分区编号 0~3（识别0x02后有效；扫描0x03后=0）
- 箱0~7 = 各箱归位区编号 0~3，**0xFF=未检测**

### A→B 移动帧 14字节 `EF f1 f2 f3 FE`（3×float小端）
- f1=x轴标志、f2=y轴标志、f3=yaw标志，值 0.0不动/1.0正/2.0负
- 主机每帧挪一个固定小步长后停
