# 任务赛决策机 · v3 方案说明（四视角 + 全流程）

> 给人看的方案稿，不是代码手册。目标：把"一趟搬两箱"这件事，从**主状态机、狗底盘、导航、机械臂**四个角色分别讲清各自在每一步干什么，最后合成一条从头到尾的完整流程。先审这份，没问题再落到文档和代码。

## 0. 一句话方案

**跑一趟、搬两箱、完赛即可。** 狗在启动区原地看题看箱 → 挑一条"两箱不同色"的缝钻进去 → 只抓靠减速带那排的两个箱 → 直穿减速带 → 到归位区把两个箱按颜色各放一个。全程只搬 4 个候选箱里的 2 个，够到"每个颜色都有箱"的最低完赛线。

几个贯穿全场的铁律，先记住：
- **只抓 back 排**（靠减速带那排，编号 idx0-3），front 排（靠启动区，idx4-7）看都不看。
- **一趟两箱必须异色**；哪条缝的两箱同色就弃哪条。
- **微调只在"停下之后"发生**：导航把狗停在固定点 → 发抓/放命令 → 机械臂发现差一点、回传一个微调距离 → 主状态机稳稳挪狗 → 机械臂接着干。狗动的时候机械臂不看（一动摄像头就不准），这是"停-发-调-干"的由来。

## 1. 四个角色是谁

```
        ┌─────────────────────────────────────────┐
        │            主状态机 (决策机 B)             │
        │   看谁都归它管，自己不干活，只发号施令       │
        └───────┬───────────────────────┬──────────┘
         串口命令 │                       │ navigate_to_pose
                ▼                       ▼
        ┌──────────────┐        ┌──────────────┐
        │  机械臂 (X5)  │        │   导航 FSM    │
        │  眼 + 手      │        │   算路径      │
        └──────────────┘        └──────┬───────┘
                                       │ /cmd_vel
                                       ▼
                                ┌──────────────┐
                                │   狗底盘      │
                                │   腿          │
                                └──────────────┘
        ▲ 微调时主状态机也直接发 /cmd_vel_raw 给底盘挪一小步
```

- **主状态机**：教练。掌握全局，决定现在该走哪、该抓哪、该放哪，但自己不迈腿不伸手。
- **狗底盘**：腿。已验证，收速度指令就能走，能走到导航给的点。
- **导航**：算路人。给它一个目标点名，它规划路径、驱动腿走过去，到了就报"成功"。已验证。
- **机械臂 X5**：眼睛 + 手。识别题目、认箱子颜色、抓、放；对不准时不会自己乱动，而是回头喊主状态机"帮我把狗挪 X 厘米"。

## 2. 主状态机视角：每个状态干什么

主状态机是整场的剧本，按顺序走这几幕：

| 状态 | 干什么 | 结束条件 |
|------|--------|---------|
| **S0 初始化** | 开串口、等导航服务上线、按名册点清 18 个路点、给机械臂发"初始化"命令 | 机械臂回复初始化完成 |
| **S1 识别 + 扫描** | 狗待在启动区不动，发"数字识别"→收答案；发"扫描8箱"→收 8 个箱色。全程原地，让机械臂看得清 | 收齐答案 + 8 箱色 |
| **S2 规划** | 就这一步动脑：从三条缝里挑出**两箱异色**的缝，含高分箱的优先。定下这趟走哪条缝、抓哪两箱 | 选定 1 条缝 |
| **S3 进场到缝** | 指挥导航依次走 home→entry→gapXX_pre→gapXX_back，把狗停在缝正中 | 狗停在缝中固定点 |
| **S4 抓两箱** | 发"抓右"→（停-发-调-干闭环）→发"抓左"→（同上）。抓的过程中记住左右托盘各是什么色 | 两箱都在托盘上 |
| **S5 过减速带** | 指挥导航从缝中直线穿过减速带，停在本缝正前方的带后点 | 狗停在 zoneXX_approach |
| **S6 放两箱** | 按托盘颜色，横移到第一个颜色区→发"放置"→（停-发-调-干）→横移到第二个颜色区→发"放置"→（同上） | 两箱都落进正确颜色区 ✅ 完赛 |

> 阶段1到 S6 就算赢了，狗停哪不管。返程和跑第二趟是以后的事。

**"停-发-调-干"闭环**（S4 抓、S6 放都用它，是全场唯一需要主状态机实时控底盘的地方）：

```
导航把狗停在固定点  →  主状态机发命令(抓/放)  →  机械臂试着干
                                                    │
                              对得准 ─────────────┤
                                                    │
                              差一点，回传"需微调 + 差多少距离"
                                                    ▼
                          主状态机把这个距离换成"底盘慢速走多久"，稳稳挪过去
                                                    │
                                                    ▼
                          挪完，机械臂自己接着干（可能再差一点，再来一轮）
                                                    │
                                                    ▼
                                        机械臂回"完成" → 这一箱搞定
```

## 3. 狗底盘视角：什么时候听谁的

底盘很单纯，只管走，但它的速度指令**来自两个上级**，分时复用：

| 时机 | 谁在指挥 | 底盘在干什么 |
|------|---------|-------------|
| 大段赶路（进场、进缝、过带、横移到区） | 导航 FSM | 按规划的路径正常走到目标点 |
| 停在固定点、机械臂要微调时 | 主状态机直接发 | 收一个很小的速度，慢慢挪几厘米，挪完立刻停 |
| 没人指挥时 | —— | 站着不动（导航空闲不发指令） |

两个上级不会打架：微调走的是一条带"限速 + 断流自动刹停"保险的通道，就算主状态机忘了发停止，狗也会自己停下，不会失控乱冲。**微调强调"稳"**——宁可慢、宁可分几次挪，也不要一把冲过头，因为冲过头机械臂又得重新对。

## 4. 导航视角：只负责"把狗停到正确的点"

导航是个"点到点"的服务：主状态机报一个点名，它就把狗送过去，到了报成功。它**不参与抓放、不参与微调**，一趟里它被调用这么几次：

| 第几段 | 从哪到哪 | 备注 |
|--------|---------|------|
| ① | home → entry | 出发集结 |
| ② | entry → gapXX_pre | 到选定缝的正前方，把身体摆正对缝 |
| ③ | gapXX_pre → gapXX_back | 钻进缝、停在靠减速带那排的抓取位 |
| ④ | gapXX_back → zoneXX_approach | 从缝里**直线**穿过减速带（这两个点故意打在同一条纵线上，所以是直穿不是斜穿） |
| ⑤ | zoneXX_approach → 第一个颜色区 | 横移对准 |
| ⑥ | 第一个区 → 第二个颜色区 | 放完第一箱再横移到第二个区 |

导航的每一段都是"停稳了才算到"，停稳之后主状态机才会发下一步命令——这是"停-发-调-干"里"停"的保证。18 个打点里，导航要用到的是：home、entry、gapXX_pre×3、gapXX_back×3、zoneXX_approach×3、place_×4，实际一趟只碰其中约 8 个。

## 5. 机械臂视角：眼和手，对不准就喊挪狗

机械臂是执行端，主状态机发一条它干一条，干完回一条"完成"。它在各阶段的活：

| 主状态机发来 | 机械臂干什么 | 回什么 |
|-------------|-------------|--------|
| 初始化 | 自检、归位 | 完成 |
| 数字识别 | 看题板，算出答案 | 答案 + （占位）8 箱色 |
| 扫描 8 箱 | 扫一遍 8 个箱，认颜色 | 8 箱色 |
| 抓右 / 抓左 | 视觉对准目标箱去抓 | 对得准→直接完成；差一点→先喊"需微调+距离"，等狗挪好再继续，最后完成 |
| 放置 | 把当前托盘的箱放到面前的区 | 同上，可能先喊微调 |

关键点：**机械臂只在狗停稳时工作**，狗一动它就不看（摄像头识别不准）。所以它对不准时不会自己指挥狗动，而是把"还差多少"这个距离回传给主状态机，由主状态机稳稳挪，挪完它再看、再对。抓箱时它还顺便把左右两个托盘各放了什么颜色记下来告诉主状态机，供放置时决定去哪个区。

## 6. 从头到尾一整趟

> 设这场：识别答案 = 蓝（高分色是蓝），扫描出 back 排四箱 = [红, 蓝, 灰, 绿]（idx0-3）。

### 6.1 箭头流程图（一眼看懂版）

```
🏁 起跑线：狗蹲在启动区
   │
   ▼
【S0 开机自检】主状态机：串口通✓ 导航在线✓ 18个点齐✓ 机械臂就绪✓
   │
   ▼
【S1 读题看箱】狗原地不动
   ├─ 机械臂看题板 ──→ 算出「答案 = 蓝」（蓝是高分色）
   └─ 机械臂扫8箱 ──→ back排 =「红 蓝 灰 绿」(idx0 1 2 3)
   │
   ▼
【S2 掐指一算】主状态机挑缝：
   gap01→红+蓝 ✅异色 且含高分蓝 ⭐
   gap12→蓝+灰 ✅异色
   gap23→灰+绿 ✅异色
   ═══ 选定 gap01（异色 + 有高分）═══
   │
   ▼
【S3 进场】主状态机喊导航，狗一路走：
   home ──→ entry ──→ gap01正前方 ──→ 钻进缝，停在红蓝两箱中间
   │
   ▼
【S4 抓两箱】(狗停稳，进入「停-发-调-干」)
   ┌──────────────────────────────────────────────┐
   │ 抓右：发命令 → 机械臂瞄蓝箱「差2cm」            │
   │        → 主状态机稳稳挪狗2cm → 机械臂抓起蓝箱    │
   │        → 记「右托盘 = 蓝」✓                     │
   │ 抓左：发命令 → 机械臂瞄红箱 →(可能再微调)        │
   │        → 抓起红箱 → 记「左托盘 = 红」✓           │
   └──────────────────────────────────────────────┘
   │  两箱到手 🧰
   ▼
【S5 过减速带】主状态机喊导航：
   缝中 ══直线碾过减速带══▶ gap01带后点（不歪不斜，两点在同一纵线）
   │
   ▼
【S6 放两箱】(每个区都是「停-发-调-干」)
   横移到🟥红区 → 发放置 →(微调)→ 机械臂把红箱推进红区 ✓
        │
   横移到🟦蓝区 → 发放置 →(微调)→ 机械臂把蓝箱推进蓝区 ✓
   │
   ▼
🏁 完赛！红箱进红区、蓝箱进蓝区，一趟两箱各就各位
```

**三句话记住全流程**：
- **看**（原地识别+扫描）→ **想**（选一条异色缝）→ **抓**（缝里抓两箱）→ **过**（直穿减速带）→ **放**（横移到区各放一个）
- 凡是"抓"和"放"，都是同一个套路：**停稳 → 发命令 → 机械臂喊差多少 → 主状态机挪狗 → 机械臂接着干**
- 狗动时机械臂闭眼，机械臂看时狗不动 —— 两者永不同时动

### 6.2 叙事版（配合上图读）

**开局**。狗蹲在启动区，像运动员在起跑线。裁判一声令下，主状态机开机自检：串口通了、导航服务在线、18 个打点一个不缺、机械臂也报告"初始化好了"。**（S0）**

**读题看箱**。狗一步不挪，机械臂抬头看题板——"算出来是蓝色高分"；再低头把面前四个箱扫一遍——"从左到右：红、蓝、灰、绿"。主状态机把这些记在心里。**（S1）**

**掐指一算**。主状态机盘算三条缝：gap01 面对红、蓝——俩不一样色，能要，而且蓝是高分！gap12 面对蓝、灰——也行；gap23 面对灰、绿——也行。红蓝这条既异色又含高分，**就走 gap01**。**（S2）**

**进场**。主状态机喊导航："去 entry。"狗起身走到集结点。"去 gap01 正前方。"狗走过去，正对缝口站定。"钻进去，停在靠减速带那排。"狗稳稳停在两个箱中间——左边红箱、右边蓝箱，伸手可及。**（S3）**

**抓箱**。主状态机发"抓右"。机械臂瞄准右边蓝箱，发现差了两厘米够不着，回喊："往右挪 2 公分。"主状态机不急，给底盘一个很轻的速度，让狗蹭过去，稳稳停下。机械臂再看——正好，一把抓起蓝箱放右托盘，回报"完成"。主状态机心里记下"右托盘=蓝"。接着发"抓左"，同样的停-发-调-干，红箱进了左托盘，"左托盘=红"。**（S4）**

**过带**。两个箱到手。主状态机喊导航："去 gap01 的带后点。"因为这个点就打在缝的正前方，狗是笔直地碾过减速带过去的，不歪不斜，停在归位区前。**（S5）**

**放箱**。主状态机看看手里：左红、右蓝。它决定先放红——横移到红色区正前方站定，发"放置第1层"。机械臂对红区，差一点，回喊微调，主状态机挪一下，机械臂把红箱往前推进红区。再横移到蓝色区，同样放下蓝箱。**（S6）**

**完赛**。两个箱，一个红一个蓝，各就各位。这一趟的任务达成——按 v3 的目标，到此就是完赛。狗停在原地喘口气，主状态机打印战报。🏁

## 7. 请你重点看这几处对不对

1. **只抓 back 排、front 全弃** —— 一趟就 2 箱，选一条异色缝，对吗？
2. **"停-发-调-干"** —— 抓和放都是先导航停稳、再发命令、机械臂回传微调距离、主状态机控底盘挪、机械臂接着干，对吗？
3. **微调是"距离值"** —— 机械臂给的是"还差多少距离"，主状态机自己换算成速度×时间稳稳挪，不是照着位移一把冲，对吗？
4. **放置靠托盘记色** —— 抓时记住左右托盘颜色，放时按颜色决定去哪个区，对吗？
5. **选缝优先级** —— 先要异色（同色弃），再在异色缝里挑含高分箱的，对吗？
