# simple_dicision 实测命令

> 每开新终端第一件事：`source ~/dog_auto/setup-env.sh`

---

## 一、准备阶段：验证重定位

```bash
# 终端1: 狗底盘
source ~/dog_auto/setup-env.sh
ros2 launch nav_bringup dog_bringup.launch.py

# 终端2: 定位 arena 地图（开 Rviz 看重定位）
source ~/dog_auto/setup-env.sh
ros2 launch nav_bringup dog_navigation.launch.py map_name:=arena run_nav2:=False use_rviz:=true
```

盯 Rviz：狗实际位置是否稳定在地图上。

| 现象 | 判断 |
|------|------|
| 狗位置稳定、不飘 | ✅ 重定位 OK → 走方案A |
| 狗位置一直飘、GICP 不收敛 | ❌ → 走方案B |

---

## 二、方案A：重定位 OK

```bash
# 终端1: 狗底盘
source ~/dog_auto/setup-env.sh
ros2 launch nav_bringup dog_bringup.launch.py

# 终端2: 定位 arena
source ~/dog_auto/setup-env.sh
ros2 launch nav_bringup dog_navigation.launch.py map_name:=arena run_nav2:=False use_rviz:=true

# 终端3: 导航 FSM（遥控器 ch5 高位或拔掉）
source ~/dog_auto/setup-env.sh
ros2 launch simple_nav_fsm simple_nav.launch.py

# 终端4: 决策机
source ~/dog_auto/setup-env.sh
ros2 launch simple_dicision simple_mission.launch.py \
  left_color:=red right_color:=blue auto_start:=False

记得改左右箱子颜色！！！！！！！！！！！！！

# 定位稳了 → 扳机
ros2 service call /simple_dicision/start std_srvs/srv/Trigger
```

---

## 三、方案B：重定位飘 → 关重定位

```bash
# 终端1: 狗底盘
source ~/dog_auto/setup-env.sh
ros2 launch nav_bringup dog_bringup.launch.py

# 终端2: 定位（slam:=True 关重定位，纯靠里程计，不做地图配准）
source ~/dog_auto/setup-env.sh
ros2 launch nav_bringup dog_navigation.launch.py map_name:=arena slam:=True run_nav2:=False use_rviz:=true

# 终端3: 导航 FSM
source ~/dog_auto/setup-env.sh
ros2 launch simple_nav_fsm simple_nav.launch.py

# 终端4: 决策机
source ~/dog_auto/setup-env.sh
ros2 launch simple_dicision simple_mission.launch.py \
  left_color:=red right_color:=blue auto_start:=False


记得改左右箱子颜色！！！！！！！！！！！！！

# 扳机
ros2 service call /simple_dicision/start std_srvs/srv/Trigger
```

> 方案B 代价：里程计随时间漂移，跑久了到点会有偏差。

---

## 四、急停

```bash
ros2 service call /simple_dicision/abort std_srvs/srv/Trigger
```

---

## 五、旁观状态

```bash
ros2 topic echo /simple_dicision/phase    # 决策机当前阶段
ros2 topic echo /simple_nav_fsm/state     # 导航 FSM 状态
```

## 六、换场地

编辑 `config/mission.yaml`，改路点名匹配新场地的打点：

```yaml
route:
  start:    "1"
  grab:     "42"
  cross:    "52"
  place_green:  "64"
  place_gray:   "63"
  place_blue:   "62"
  place_red:    "61"
```

改完编译：

```bash
cd ~/dog_auto && colcon build --packages-select simple_dicision --symlink-install
```
